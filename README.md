# NabiOta Medical Care Center (MVZ) for General and Specialist Care

Multilingual web application for NabiOta MVZ (Medizinisches Versorgungszentrum für hausärztliche und fachärztliche Versorgung GmbH).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production Build

To build the application for production:

```bash
npm run build
```
