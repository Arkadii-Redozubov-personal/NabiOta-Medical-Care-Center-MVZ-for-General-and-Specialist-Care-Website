# NabiOta Medical Care Center (MVZ) for General and Specialist Care

Multilingual web application for NabiOta MVZ (Medizinisches Versorgungszentrum für hausärztliche und fachärztliche Versorgung GmbH).

## Project Structure

- `legacy-adapted/` — Next.js application with modernized UI/UX, responsive layouts, 6-language localization (`de`, `en`, `ru`, `tr`, `ar`, `uz`), interactive components, and high-performance static page generation.

## Getting Started

```bash
cd legacy-adapted
npm install
npm run dev
```

Build for production:

```bash
cd legacy-adapted
npm run build
```
